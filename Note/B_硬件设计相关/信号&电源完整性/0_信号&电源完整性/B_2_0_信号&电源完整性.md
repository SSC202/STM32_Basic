# 信号完整性 电源完整性

信号完整性（SI），电源完整性（PI），电磁兼容（EMC）是同一个系统的不同电气表现。

> - SI：信号到达接收端时能否被正确识别；
> - PI：器件工作时的供电电压能否保持在允许范围内；
> - EMC：系统能否在电磁环境中正常工作，同时不对外界产生过大电磁干扰。

| 领域 | 关注对象       | 常见问题                     | 可能的结果                   |
| ---- | -------------- | ---------------------------- | ---------------------------- |
| SI   | 信号链路       | 反射、振铃、串扰、边沿退化   | 误触发、误码、时序错误       |
| PI   | 电源分配网络   | 电压跌落、纹波、地弹、电源弹 | 芯片复位、工作异常、信号抖动 |
| EMC  | 系统与电磁环境 | 传导和辐射发射、外部干扰     | 干扰其他设备，或自身受到干扰 |

---

SI，PI，EMC 关注的问题可以分为以下六类：

1. 单条信号链路失真 - 过冲/下冲/振铃

   信号沿互连线传播时，如果遇到阻抗变化，一部分能量会反射。反射波与原信号叠加，就可能形成过冲、下冲、振铃或非单调边沿。

   常见的不连续结构包括接收端、分支、过孔、连接器，以及走线宽度或参考平面的变化。

2. 有损互连 - 边缘退化

   实际互连会损耗信号能量，而且损耗通常随频率变化。数字信号的快速边沿包含较多高频成分，高频成分衰减后，接收端的信号边沿会变缓。

   损耗主要来自导体和介质损耗。

3. 串扰 - 噪声耦合

   相邻信号路径之间存在电场和磁场耦合。一条线上的电压或电流变化，可能在另一条线上产生噪声。

4. 地弹/电源弹

   芯片内部有多个电路同时开关时，变化的电流会流过封装引脚、过孔和平面等结构。这些路径有阻抗，因此不同位置的电位可能发生短暂变化。

5. 电源轨塌陷

   芯片的负载电流突然增大时，电源分配网络需要提供额外电流。由于稳压器、电容、封装和 PCB 互连都不是理想器件，芯片电源端的电压可能暂时下降，或发生振荡。
